## Introduction
### Pandas
[**pandas**](https://pandas.pydata.org/) is a fast, powerful, flexible and easy to use open source data analysis and manipulation tool, built on top of the [Python](https://www.python.org) programming language.
### Numpy
[**NumPy**](https://numpy.org/) (Numerical Python) is a core open-source library for the Python programming language. It adds support for large, multi-dimensional arrays and matrices, along with fast mathematical and vector functions to operate on these data structures
