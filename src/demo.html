HOVER TO DIFFUSE

Built with two source photos, each converted to a two-color duotone via luminance thresholding, then dissolved using a fixed per-pixel noise field: on hover, pixels reveal image B in the order given by noise[p] < progress — the same logic as error-diffusion dithering, just animated over time.
